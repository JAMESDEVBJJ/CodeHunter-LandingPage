# CodeHunter 🚀

CodeHunter é uma landing page desenvolvida para apresentar uma solução focada em facilitar a busca por vagas de tecnologia.

O projeto foi criado por estudantes de TI da Unicesusc com o objetivo de centralizar oportunidades de emprego que muitas vezes ficam espalhadas em diferentes plataformas e sites de empresas.

## Funcionalidades

- Busca centralizada de vagas
- Interface moderna e responsiva
- Navegação simples e intuitiva
- Organização visual limpa
- Landing page com múltiplas seções

## 🛠 Tecnologias utilizadas

- React
- TypeScript
- React Router DOM
- CSS

## 📚 Objetivo

Facilitar a conexão entre desenvolvedores e oportunidades reais de emprego, tornando a busca mais rápida, prática e eficiente.

## ▶ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/seuusuario/codehunter.git
```

Entre na pasta do projeto:

```bash
cd codehunter
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

O projeto ficará disponível em:

```txt
http://localhost:5173
```
